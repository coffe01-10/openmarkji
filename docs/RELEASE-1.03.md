# OpenMarkji 1.03

本版加入 WebDAV 备份，完善学习日历与用时统计，并改进搜索、选卡和学习交互。

## 本版内容

- 资料与备份新增 WebDAV 入口，点开后可填写服务器信息、上传完整 ZIP 备份或恢复远端资料。连接信息仅保存在本机，恢复前保留旧资料；完整词库使用批量写入加快恢复。
- 学习日历按周一至周日排列，支持翻月和查看每日记录。固定六行高度，切换月份不再伸缩，并移除“回到本月”按钮。
- 今日页面显示当天学习用时，统计页面显示历史累计用时；新增专项练习用时记录，不影响长期排期。旧版本未记录的专项练习用时无法补算。
- 三张统计卡片的数值共用字号并保持对齐，时长使用 `分:秒` 或 `小时:分` 显示，单位单独排列。
- 牌组搜索支持查找具体卡片的问题、答案和标签；牌组选卡页的写卡片、导入、搜索和筛选工具随滚动收起、展开。
- 修复批量拖选松手后仍持续选择的问题；在其他导航页按系统返回键先回到今日。
- 改进加入计划的收缩、加载、勾选和恢复动画，减少评分切卡与揭示答案时的闪烁。
- 优化首次进入今日页和统计页的加载，统一牌组与设置页面转场，完善编辑器控件和卡片语法文案。

## 下载安装

支持 Android 7.0 及以上。已安装旧版的用户请选择相同架构的 APK 覆盖安装，无需卸载应用。

- **OpenMarkji-1.03-android-arm64-v8a.apk**：大多数现代 Android 手机，优先选择。
- **OpenMarkji-1.03-android-armeabi-v7a.apk**：较旧的 32 位 ARM Android 设备。
- **OpenMarkji-1.03-android-x86_64.apk**：x86_64 Android 设备及模拟器。

APK 显示版本为 **1.03**，内部版本为 `1.0.3+4`。应用内检查更新继续使用现有公开更新源。
