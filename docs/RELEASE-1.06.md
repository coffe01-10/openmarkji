# OpenMarkji 1.06

本版改进牌组卡片搜索与筛选，统一设置页的沉浸式顶栏，并修复统计滚动跳动和优化学习动画。

## 界面与体验

- **沉浸式设置顶栏**：外观与阅读、学习偏好、资料与备份、学习提醒等设置详情页沿用主页的渐变淡出效果，内容可滚入标题和状态栏下方，保留原有进入与返回动画。
- **统计滚动修复**：修复从统计页底部缓慢向上滑动时，内容突然跳过一段距离的问题。
- **学习动画**：优化今日页、背诵与专项练习的进度、揭晓答案、评分和卡片切换动画，选择题反馈与挖空揭晓过渡更自然。
- **搜索与筛选**：搜索单词时优先显示开头命中的卡片；改进标签筛选，列表、结果计数与全选使用一致条件，全选大牌组时减少内容解析。
- **卡片预览**：列表中区分题面和答案的视觉层级，高亮搜索词，改善无搜索结果和无匹配卡片时的提示。

## 下载安装

支持 Android 7.0 及以上。选择与已安装版本相同架构的 APK 覆盖安装，无需卸载应用。也可在“设置 → 关于 → 检查更新”直接下载安装。

- **OpenMarkji-1.06-android-arm64-v8a.apk**：大多数现代 Android 手机，优先选择。
- **OpenMarkji-1.06-android-armeabi-v7a.apk**：较旧的 32 位 ARM Android 设备。
- **OpenMarkji-1.06-android-x86_64.apk**：x86_64 Android 设备及模拟器。

显示版本为 **1.06**，内部版本为 `1.0.6+7`。安装包沿用现有签名，尚未配置正式发布密钥。
