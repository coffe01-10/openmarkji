# WebDAV 备份

进入「设置 → 资料与备份 → WebDAV 备份」，填写 WebDAV 服务器目录地址、用户名、密码或应用专用密码和备份目录，然后点击「连接并刷新」。备份目录相对于服务器地址，不存在时自动创建；地址需直接指向最终目录，不使用网页分享链接。

连接成功后，「备份到 WebDAV」上传一份带时间戳的 ZIP 文件。远端列表中的「恢复」会替换本机资料，恢复前的数据可从「导出恢复前的资料」取回。这里提供手动备份与恢复，不会自动合并不同设备的修改。

备份包含牌组、共享卡片关系、图片、学习记录、练习进度和设置。WebDAV 连接信息仅保存在本机，不包含在 ZIP 中，恢复也不会覆盖本机连接信息。备份文件本身未加密，请使用自己的可信服务器和 HTTPS 地址。

网页版需要服务器允许当前网页来源跨域访问，并支持 `PROPFIND`、`MKCOL`、`PUT`、`GET`，允许 `Authorization`、`Depth`、`Content-Type` 请求头。HTTPS 网页连接 HTTP 服务器还会受浏览器混合内容限制。Android 等原生版本不受浏览器 CORS 限制。

学习时长包括正式学习、重学和此版本开始记录的专项练习。今日页面显示当天累计用时，统计页面显示全部历史累计用时；旧版本未记录的专项练习用时无法补算。学习日历按周一至周日排列，支持翻月和查看某一天的次数与用时。
