# OpenMarkji 1.01

离线优先的记忆卡应用，支持墨墨语法、MMX 调度与每日学习计划。

## 本版内容

- 统一 FlClash 风格液态玻璃：导航、分段切换栏支持按住滑动和松手回弹；按钮、搜索框与菜单共用外观设置。
- 外观页提供全局玻璃档位、透明度和背景模糊设置，拖动实时预览，固定导航模式也可调整。
- 遗忘曲线、学习情况和记忆持久度统计，支持时间粒度切换、横向滑动及日期选点。
- 紧凑卡片列表、拖动批量选择、收藏和难卡筛选，改进搜索、编辑、导入与专项练习流程。
- 支持 MMX-5／MMX-6、每日学习计划、评分撤销、同日重学与本地备份恢复。

## 下载安装

支持 Android 7.0 及以上。

- **OpenMarkji-1.01-android-arm64-v8a.apk**：大多数现代 Android 手机，优先选择。
- **OpenMarkji-1.01-android-armeabi-v7a.apk**：较旧的 32 位 ARM Android 设备。
- **OpenMarkji-1.01-android-x86_64.apk**：x86_64 Android 设备及模拟器。

APK 显示版本为 **1.01**；Flutter 内部版本为 `1.0.1+2`。

安装包为 Release 构建，沿用仓库现有的测试签名，尚未配置正式发布密钥。Android 系统文件选择器、动态取色等设备行为尚未完成实机验证。
