# OpenMarkji 1.02

本版完善牌组管理，修复拖拽与专项练习中的闪烁，并适配 Android 沉浸式状态栏。

## 本版内容

- 牌组支持长按拖拽排序，靠近屏幕边缘时自动滚动；排序会保存，筛选时不会打乱其他分组的牌组。
- 官方牌组不再提供删除入口，数据层同步保护官方牌组和共享卡片；自建牌组仍可正常删除。
- 修复拖拽原位释放时出现加载圈、牌组撑高，以及排序保存期间回跳、连续拖动后闪烁的问题。
- 修复专项练习切换范围、数量与随机顺序时的重复加载和表单位移。
- 适配 Android 沉浸式状态栏，页面背景延伸到系统栏，标题与操作按钮避让安全区域。
- 改进学习统计图表、设置页面过渡和中断后状态恢复，更新 README 与应用内 GPL-3.0 许可说明。
- 继续提供默认公开更新源，旧版可通过应用内“检查更新”获取本版信息。

## 下载安装

支持 Android 7.0 及以上。已安装 1.01 的用户可使用相同架构的 APK 覆盖安装，无需卸载应用。

- **OpenMarkji-1.02-android-arm64-v8a.apk**：大多数现代 Android 手机，优先选择。
- **OpenMarkji-1.02-android-armeabi-v7a.apk**：较旧的 32 位 ARM Android 设备。
- **OpenMarkji-1.02-android-x86_64.apk**：x86_64 Android 设备及模拟器。

APK 显示版本为 **1.02**，内部版本为 `1.0.2+3`。

## 验证

完整测试 89 项通过，静态分析无问题。内置浏览器已验证牌组原位释放、改变顺序及恢复顺序，以及专项练习范围和数量切换；逐帧回归同时覆盖延迟读写与连续拖动。

安装包为 Release 构建，沿用 1.01 的现有测试签名，尚未配置正式发布密钥。Android 系统文件选择器、动态取色和不同设备的系统栏表现仍需实机反馈。
