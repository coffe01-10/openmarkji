# OpenMarkji 1.05

本版新增选择题卡片、卡片引用、更多导入方式和 Android 学习提醒，并改进统计图表与设置动效。

## 新功能

- **选择题卡片 `[Choice]`**：支持制作和导入单选、多选题，可随机排列选项；提交后显示作答反馈，全对建议“认识”、仅漏选建议“模糊”、选错建议“忘记”，最终由你确认评分。
- **卡片引用 `[Ref]`**：可在编辑器中搜索插入引用，点击后预览并跳转到关联卡片；每日学习页支持右滑返回上一张卡片，撤销最近一次评分。
- **导入与分享**：支持 xlsx、CSV、TSV 列映射导入，Anki `.apkg` / `.colpkg` 导入，以及包含卡片和图片的 `.omdeck` 牌组分享包。导入内容不带入其他应用的学习排期。
- **Android 学习提醒**：在“设置 → 学习提醒”开启，每天按本地时间发送“今日待复习 N 张”；发送时读取实际未完成的到期复习，没有到期复习时不提醒。可设置提醒时间、发送测试通知，重启设备后恢复安排。
- **专项练习默认值**：在学习偏好中设置每轮默认数量和随机顺序，开始练习前仍可单独调整。

## 界面与体验

- 改进遗忘曲线、学习情况和记忆持久度图表的配色与绘制，优化图例和选中日期展示。
- 更新应用图标与关于页面，统一玻璃弹窗和各级设置入口的展开、返回与菜单动画。
- 重做今日待复习卡片，精简统计页和提醒页的说明文字。
- 修复修改提醒时间后返回动画短暂回显旧值，以及首次加载数字与占位符重叠的问题。

## 下载安装

支持 Android 7.0 及以上。选择与已安装版本相同架构的 APK 覆盖安装，无需卸载应用。1.04 用户也可在“设置 → 关于 → 检查更新”内直接下载并交给系统安装。

- **OpenMarkji-1.05-android-arm64-v8a.apk**：大多数现代 Android 手机，优先选择。
- **OpenMarkji-1.05-android-armeabi-v7a.apk**：较旧的 32 位 ARM Android 设备。
- **OpenMarkji-1.05-android-x86_64.apk**：x86_64 Android 设备及模拟器。

显示版本为 **1.05**，内部版本为 `1.0.5+6`。安装包沿用现有签名，尚未配置正式发布密钥。
