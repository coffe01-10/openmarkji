# 卡片语法与文本导入

## 从文本到学习计划

进入牌组 → 导入 → 粘贴文本或选择 TXT → 设定卡片分隔行 → 预览并排除不需要的条目 → 选择牌组和章节 → 导入。

支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM。导入失败会显示原因，现有资料不受影响。相同源码默认在目标牌组内跳过，也可开启保留重复；不同源码始终新增，不覆盖已有卡片。

导入后卡片位于资料库。选中卡片或整个筛选结果后，“加入计划”才会安排新学。

## 其他来源

导入页顶部可切换来源。文件来源默认导入同名新牌组，也可改选已有牌组。

- **表格**：xlsx（第一张工作表）、CSV、TSV。逐列指定问题、答案（可多列，按顺序换行合并）、标签和章节；表头含“标签”“章节”时自动识别。单元格按纯文本导入，CSV 需为 UTF-8，旧版 xls 请先另存为 xlsx。
- **Anki**：`.apkg` / `.colpkg`，支持新旧数据库格式。按笔记模板生成问答卡，加粗、斜体、下划线、换行、图片和 MathJax 公式会转换；挖空笔记合并为一张分组挖空卡；子牌组作为章节，标签保留。音频暂不支持，Anki 的复习记录不会带入。
- **分享包**：牌组更多操作中的“导出分享包”生成 `.omdeck`，包含卡片、章节、标签和引用的图片，不含学习记录与排期，对方选择“分享包”即可导入。

图片按内容去重写入媒体库，不会覆盖本机已有图片。

## 卡片之间怎样分隔

留空分隔设置时，整份文本作为一张卡。多卡导入时，填写原文中**独立一行**的分隔文字，例如：

```text
什么是主动回忆？
---
在查看答案之前，尝试从记忆中提取知识。
===CARD===
勾股定理是什么？
---
[E##a^2+b^2=c^2]
```

分隔设置填写 `===CARD===`，即可得到两张卡。本应用导出的多卡 TXT 也使用这一分隔行。导入其他来源的文本时，请按原文设置分隔行。

- 不根据空行切卡，避免拆坏段落。
- `---` 始终是答案线，不能用作跨卡分隔。
- 分隔文字出现在多行公式、段落语法等内部时，保留为内容。
- 纯文本模式可额外填写题答分隔文字，例如 `答案：`，每张卡以首次出现的位置拆分。
- 导入预览可以逐卡检查和排除；没有合适分隔时可分次粘贴。

## 编写卡片

| 内容 | 例子 |
| --- | --- |
| 普通文字与换行 | 直接输入文字 |
| 加粗／斜体／下划线 | `[T#B,I,U#重点]` |
| 颜色／高亮 | `[T#!e53935#红色]`、`[T#!!fff59d#高亮]` |
| 上下标 | `x[T#up#2]`、`H[T#down#2]O` |
| 链接 | `[T#link/"https://example.com"#网站]` |
| 标题／列表／对齐 | `[P#H1,center#标题]`、`[P#L#条目]` |
| 挖空 | `[F#1#答案]` |
| 独立公式 | `[E##\int_a^b f(x)dx]` |
| 图片 | `[Pic#ID/实际媒体ID#]` |
| 卡片引用 | `[Ref#ID/实际卡片ID#显示文字]` |
| 答案线 | 独立一行 `---` |

普通中括号写成 `\[` 和 `\]`。段落内支持文字样式与挖空；多行公式保持原始 LaTeX。相同挖空编号一起揭晓，不同编号可分组揭晓；长期排期仍按整卡保存。

编辑器中可以直接写源码，或使用工具栏插入常用标签、公式和本地图片。源码编辑器自动保存草稿；保存卡片后清除该草稿。

点击编辑器工具栏的“引用卡片”，搜索并选择已有卡片，会自动插入 `[Ref#ID/卡片ID#显示文字]`。引用可放在正文或段落内；点击后先预览内容，选择“打开卡片”进入详情，返回后仍留在原卡片。预览与跳转不修改评分或学习排期。引用的卡片被删除后会显示提示。

每日学习页右滑可返回上一张卡片，等同于“撤销上一次评分”：恢复该卡片评分前的学习记录和排期。目前支持撤销最近一次评分，第一页没有可返回的卡片时不会触发。

## 媒体及未支持内容

图片通过工具栏导入，原文件会复制到应用内部媒体库。文本中的图片 ID 用于关联媒体，不会自动变成可下载网址；如果缺少图片，在预览或卡片详情中关联对应的本地图片。

音频、选择题等内容暂不提供交互，原始语法保留并显示提示。图片遮罩等高级媒体行为尚未实现。语法格式错误时保留原文并提示，不会悄悄删除内容。

语法 TXT 导出保留源内容；纯文本导出用于阅读，会丢失格式信息。TXT 本身不包含图片字节或学习记录。完整迁移使用设置中的 ZIP 备份，并通过备份恢复保留媒体、记忆状态与会话。

从其他工具迁移时，先检查文本中的卡片分隔行和媒体引用，再通过导入预览确认内容。目录结构与外部媒体需要单独整理。
