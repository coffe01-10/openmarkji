# 本地首版验证记录

验证日期：2026-10-21。Flutter 3.47.7 / Dart 3.13.5，Windows 构建环境。

## 自动验证

- `flutter test --no-pub`：**41 项通过**。
- `dart analyze lib test`：**No issues found**。
- 一万张卡片的导入、分页与搜索组合测试约 **0.65–0.95 秒**；该数字是本机实测记录，不作为跨机器耗时门槛。
- Web Release 编译通过，包含本地 SQLite Wasm 与 Drift Worker。
- Android Debug 与按架构拆分的 Release 均构建通过。Release 安装包约：arm64 21.9 MB、armv7 19.7 MB、x86_64 23.3 MB。

测试覆盖原有 MMX 行为、文本转义与多行公式、编码与切卡、重复导入、JSON 迁移、每日新卡额度、真实复习时间差、重学隔离、评分事务回滚、撤销、备份和媒体恢复，以及实际制卡、导入、选卡和评分操作。

## 界面与实际操作

使用内置浏览器验证了示例创建、批量选卡加入计划、答案隐藏与揭晓、公式显示、遗忘后重学、刷新后的资料和学习进度持久化、浅深色切换，以及宽屏牌组双栏。最终宽屏页面控制台未记录错误。

界面测试覆盖 390×844 手机、360×800 且 1.6 倍字体的深色界面、900×850 宽屏，以及同编号挖空同步揭晓。

已修复验证中复现的问题：

1. 大字体下首页英文标识和日历图例溢出。
2. 进度条吞并首页学习按钮的无障碍语义。
3. 提示消息遮挡底部 Dock。
4. 面板背景遮住列表水波纹。
5. 桌面文件导出只返回路径、未写入内容。
6. 首页刷新与评分并发时，旧队列重新写回已评分卡。
7. 编辑卡片后撤销旧评分，覆盖新编辑内容。
8. Windows 中文路径的 Gradle 检查、AOT 路径乱码，以及 C/D 跨盘 Kotlin 增量缓存异常。

真实页面截图位于 `screenshots/04-*` 至 `screenshots/09-*`；旧 `01-*` 至 `03-*` 为改造前的历史截图。

## 尚未实测的边界

- 当前 ADB 设备列表为空，因此 Android 实机的系统文件选择器、动态取色、系统返回、系统栏和进程重启尚未进行设备级实测。界面和数据库相关行为已通过测试。
- 当前 APK 使用模板中的测试签名，适合安装体验；尚未配置正式发布密钥。
- 没有真实墨墨导出样本。已验证官方单卡语法与可配置的文本切分，尚未验证全部墨墨导出版本、目录结构和外部媒体还原。
- 音频、选择题、卡片引用和图片遮罩等高级内容不属于本次交互支持范围。
