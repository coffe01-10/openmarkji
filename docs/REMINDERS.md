# 学习提醒

Android 版进入「设置 → 学习提醒」，开启提醒并选择每日提醒时间，默认关闭、默认时间 20:00。提醒时间页沿用设置卡片的展开与返回收回动画，小时和分钟使用共享玻璃菜单，选择后立即保存。Android 13 及以上会在主动开启时申请通知权限；系统通知或学习提醒通知渠道被关闭时，可从页面进入系统设置。

通知内容是「今日待复习 N 张」。N 在实际发送时读取本地数据库，计算仍在计划中、已到期且今天尚未完成正式评分的卡片，包含逾期卡片；共享到多个牌组的卡片只计一次。新卡和当日重学不计入这个到期复习数量。正常提醒在 N 为 0 时跳过；「发送测试提醒」即使为 0 也会发出，便于检查通知栏。

提醒由 Android 本地闹钟与通知执行，关闭应用后仍可工作，无需联网或常驻服务。按设备本地时区计算下一次时间，设备重启、时间或时区变更及应用覆盖更新后重新安排。关闭功能会取消闹钟和已显示的学习提醒。备份恢复后也会同步提醒设置。

使用普通定时提醒，不申请精确闹钟权限；省电模式和系统后台限制可能使通知晚于所选时间。若在系统里强行停止应用，需要重新打开应用以恢复安排。

浏览器和其他平台可以查看设置与数量，但不发送 Android 本地通知。

实现说明：Dart 通过平台通道保存数据库路径；Android 在发送时只读资料库，沿用每日任务的到期复习筛选条件。通知设置仍在原有偏好数据中，无需额外迁移数据库。

参考：[Android 通知权限](https://developer.android.com/develop/ui/views/notifications/notification-permission)、[本地闹钟](https://developer.android.com/develop/background-work/services/alarms/schedule)。
