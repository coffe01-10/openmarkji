# 官方词库

这四份词表来自 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary) 的乱序文本，许可为 BSD-3-Clause。原文保留在该仓库，本目录只保留转换成 OpenMarkji 卡片的文本。

应用启动时把四套词表合并成一份词库：同一个单词不区分大小写，只保存一张卡。牌组位于「官方」分类，卡片留在资料库，不自动加入每日学习计划。界面不展示来源。

六级词表文件只收录相对四级新增的词。大学英语六级牌组在展示时并入大学英语四级的全部词汇，因此数量多于四级。考研英语和托福按各自词表完整展示。

| 文件 | 牌组 | 卡片 |
| --- | --- | --- |
| `cet4.txt` | 大学英语四级 | 7508 |
| `cet6.txt` | 大学英语六级 | 5651 |
| `kaoyan.txt` | 考研英语 | 9602 |
| `toefl.txt` | 托福 | 13477 |

每张卡以单词为问题、中文释义为答案，卡片之间使用独立一行的 `===CARD===`。

这些内容不是墨墨记忆卡或墨墨背单词的官方词库，也不包含其原版释义、例句和助记。
